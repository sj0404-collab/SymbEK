# Kenji Space

Оригинальный **Kenji-NX 2.1.0-pr.2** (их дом, GameHost, DEX, `.so`).

Поверх — только Kotlin:

- одна прошивка **на своём месте** (Eden) — без копии и без переезда
- панель только в лаунчере; в игре скрываемая кнопка, пауза (не стоп), CPU/FPS/скорость
- карточка по удержанию обложки: моды, сейвы, читы

Каждая сборка — отдельный GitHub Release `v1.0.XX` + файл в [`releases/`](releases/). Теги не затираются.

Зафиксированная рабочая точка: **[v1.0.58](https://github.com/sj0404-collab/SymbEK/releases/tag/v1.0.58)**.

Пакет `dev.symbiosis.kenji`. Нет HTML, нет React, нет WebView-UI.

# Kenji Space 1.0.117

Прошивка одна. `bis/` внутри Eden — это мы посадили рядом с `nand/`. Искатель дубликатов прав.

Теперь:

- AppPath = песочница Kenji Space, не Eden.
- Из Eden снимаем `bis/system/Contents/registered` (nand и сейвы не трогаем).
- Kenji видит прошивку только ярлыками `sandbox/bis/.../00` → Eden `nand/*.nca`.
- Копий и hardlink больше нет. Если ярлык не встаёт — не плодим второй файл.

Кнопка **данные → убрать bis из Eden**.

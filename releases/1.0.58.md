## Чем отличается от оригинала Kenji-NX 2.1.0-pr.2

Оригинал остаётся лаунчером и ядром. Space только надстраивает Kotlin `classes4.dex`.

| | Оригинал Kenji-NX | Space 1.0.58 |
|---|---|---|
| Пакет | `org.kenjinx.android` | `dev.symbiosis.kenji` |
| Прошивка | ставится в `Android/data/…/files/bis` копией | одна прошивка **на месте** (Eden `files/bis` и `nand`), без копии и без переезда |
| AppPath | свой `getExternalFilesDir` | до старта ядра указывает на `…/Download/ed/Eden/files` |
| Ключи | `system/prod.keys` | те же 12 619 Б, подкладываются в Eden `system/` |
| Автопочинка | нет | `stash`/`junk` → `registered`, ярлыки `id.nca/00` |
| UI | только их Compose | тонкая шапка + вес прошивки (234 NCA · 342.4 МБ) |
| Журнал | нет | скрыт; включается удержанием обложки |
| Оверлей FPS | их HUD | мелкий красный: FPS, масштаб, docked, PPTC/NCE, NCA |
| HTML / React / WebView | нет | нет |

Ядро, виртуальные кнопки, сетка игр, `.so` — их.

## Чем отличается от других сборок Space

- **1.0.15 / 1.0.16** — свой оверлей на весь экран, `javaInitialize` часто падал, путь логов `/.config/Ryujinx/Logs`.
- **1.0.40–1.0.55** — мост в `Android/data/…/bis` давал **0 NCA**, вечный Loading, хотя сканер видел 234 NCA в Eden.
- **1.0.56** — прошивка заработала (AppPath=Eden), но журнал раздувал шапку и блокировал запуск.
- **1.0.57** — шапка короткая, журнал в отдельном окне.
- **1.0.58** (этот) — игра стартует; красный FPS; журнал скрыт; удержание обложки открывает настройки оверлея. Рабочая точка, с которой идут следующие отдельные релизы.

## Что проверено на устройстве

- Ключи 12 619 Б, прошивка **234 NCA · 342.4 МБ** в Eden `bis` и `nand` (одна куча, без дубля).
- Blade Chimera `[01007FC01CF4E000]` запускается (несколько секунд Loading, затем игра).
- Доступ ко всем файлам: да.

## Чего в 1.0.58 ещё нет

Пауза вместо стопа, свой нижний оверлей вместо заводского, серая полоса Loading без анимации, прокрутка карточки, моды / сейвы / читы, плюс строго внутри лаунчера — это уже следующие отдельные релизы (`v1.0.59` и дальше), они не затирают этот файл.

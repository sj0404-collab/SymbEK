# Kenji Space 1.0.78

Отдельный релиз. Тег `v1.0.58` не трогаем.

Вместо простой полки Kenji — свой нативный лаунчер (как на скринах Symbiosis): обложка, **Запустить**, список, «+ Папка».

- **Запустить** только если есть сам файл NSP/XCI **и** обложка (из ROM/кэша/рядом). Кнопки без файла больше нет.
- Обновления `…800` не показываются как игры.
- Игра стартует в официальном Kenji (`bootPath`). В плеере только ⚙ пресетов, без наших панелей.
- Нет HTML/WebView.

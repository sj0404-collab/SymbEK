# Релизы Kenji Space

Каждая сборка — **отдельный** GitHub Release: тег `v1.0.XX`, файл `Kenji-Space-1.0.XX.apk` и свой `releases/1.0.XX.md`.

Старые теги **не удаляются**. В репозитории может быть сколько угодно сборок рядом.

`latest` — только ярлык на самую новую. Рабочую точку смотрите по номеру, например [v1.0.58](https://github.com/sj0404-collab/SymbEK/releases/tag/v1.0.58).

# Kenji Space 1.0.90

Отдельный релиз. Тег `v1.0.58` не трогаем.

- Все полоски загрузки сняты. Вместо них одни часы с рикошетом, без затемнения экрана.
- Часы только пока крутится официальный `EmulationService`. Тап в настройках Kenji или системы их не вызывает. При уходе с MainActivity часы гаснут.
- Сканер по-прежнему ленивый и по именам: ROM, ключи, прошивка, сейвы. Без чтения тел файлов.

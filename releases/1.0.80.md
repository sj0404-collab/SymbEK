# Kenji Space 1.0.80

Отдельный релиз. Тег `v1.0.58` не трогаем.

Лаунчер больше не заглушка:

- Игры читаются с диска из **любых** выбранных папок (не только Download/ed).
- **Запустить** шлёт реальный файл в Kenji (`bootPath` + `LAUNCH_GAME`).
- Обложки из ROM/кэша/рядом; без обложки игра всё равно в списке.
- **Настройки**: папка игр, Eden/files, сейвы, пресеты, «Починить всё». Смена папки пересобирает список и прошивку.

# Kenji Space 1.0.77

Отдельный релиз. Тег `v1.0.58` не трогаем.

Больше нет полноэкранных индикаторов и чужих окон поверх Kenji.

- «+» только внизу на полке, в плеере его нет.
- «Начать игру» внизу под обложками — только если есть ключи, прошивка и обложка/NSP.
- После нажатия — маленький секундомер, его можно таскать (рикошет). Исчезает, как только в игре слышен звук.
- В игре только плавающая ⚙ с пресетами. Официальный FPS Kenji (кнопка 60) не трогаем.
- Нет FLAG_SECURE, нет overlay-окон, нет logcat и обхода чужих окон — шторка, скрин и фон не должны отваливаться.
